# 📝 Smart To-Do List Manager (Python CLI)

A reliable command-line task management utility built in Python. It features persistent local data storage using text files (`tasks.txt`), letting you track, complete, and organize daily tasks seamlessly.

---

## ✨ Features
- **Persistent Storage:** Automatically saves tasks to a local text file so your data remains intact even after closing the application.
- **Task Status Tracking:** Easily toggle tasks between `[Pending]` and `[Completed]` states.
- **Interactive Menu:** Clean loop-based terminal navigation to view, add, modify, and delete tasks.
- **Zero Dependencies:** Built entirely using Python's core libraries—no external installations required!

---

## 🚀 How to Run

1. Make sure **Python** is installed on your computer.
2. Clone or download this repository.
3. Open your terminal or VS Code in the project folder.
4. Run the application using the following command:

```bash
python todo_manager.py
